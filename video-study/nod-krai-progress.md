# 挪德卡莱全图开发记录

当前目标为最新已开放的全部岛和分区。账号已确认伦波岛神像点亮、相关剧情未完成；2560×1440，原生传送测试已成功；当前反馈同时包括走位和机关／剧情问题。

本轮结果见[分区开发包](../bettergi/nod-krai-all/README.md)和[P2修正版](../bettergi/nod-krai-p2/README.md)。全图尚未完成。

## 证据与生成

- `nod-krai.catalog.json`：冻结BetterGI 0.66.0原生点位清单，145个点、10个分区，原始清单不带可执行路线。
- `nod-krai.sources.json`：20个分P的来源、全帧解码／转写／人工审看状态；原视频、原始转写、OCR和截图留在仓库外。
- `nod-krai.campaign.json`：25个源路线区间与移动方式；21个可编译模块，4个机制门槛阻止执行。
- `nod-krai-p2.navigation.json`：12段、246点，保留帧号、时间和坐标来源；1→2仍是人工量图，5→6是未实机验证的步行变体。

`tools/collect_guide_media.py` 收集公开可用的媒体格式，校验HTTP206及每个Content-Range后组装；需要本地yt-dlp元数据。下载失败保留为失败，不声称看过缺失视频。

`tools/transcribe_guide.py` 用本地faster-whisper模型自动转写；通过FFmpeg解码成16kHz单声道数组，避免本环境PyAV版本不兼容。转写会错认方向、键名与专名，不等同于UP主字幕或人工听音。

`tools/build_guide_atlas.py` 从原生1024地图建立离线特征索引。Teyvat原点为(16384,12288)，MoonCanon为(11264,4096)，世界坐标均为原点减图像像素坐标。索引只用于研究，不在游戏中替代原生定位。

`tools/audit_guide.py` 顺序解码所有帧，用SIFT/RANSAC及最长1秒光流跟踪；记录未定位区间。小视野局部匹配须受最近3秒强锚点、尺度与速度约束。派蒙轮廓检查用于避免亮天空令整段滑翔被误判为非主界面。OCR是可选的自动采样，未声明完整审完字幕。

`tools/extract_native_route.py` 只导出明确给定移动方式的区间，拒绝未定位缺口、传送跳变和不完整解码；不插值补洞、不从XY推断机关或楼层。路线仍需逐段验证三维通行性。

`npm run build:campaign` / `npm run test:campaign` 构建并检查分区工程；`npm run build:bettergi` / `npm run test:bettergi` 检查P2。ZIP构建参数见对应Python脚本的 `--help`。

1. 在真实BetterGI中验证P2升降台、5→6斜坡步行变体和落地处理，核对失败日志的期望／实际坐标。
2. 逐段完成剩余视频画面、语音与字幕复核，补齐6.3 P4和月球主线②③画面源；不能把转写当作画面证据。
3. 接入独立地下图层证据和形态／吸附／瞄准／机关反馈识别，先完成一个机关的状态前后检查，再扩展同类模块。
4. 给每个任务锚点、聚所和隐藏高速站绑定原生复合ID及任务／供奉门槛。当前只列已核对的门槛，不猜测全部对应关系。
5. 补齐分区路径后逐段实机验收，再开放批量从零开图；当前不可宣布完成全图。
