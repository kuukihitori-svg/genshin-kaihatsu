# genshin-kaihatsu

面向 BetterGI 脚本开发的轻量任务测试沙盘。当前实现的是纯 JavaScript 世界状态与任务规则引擎，后续在云端任务中补充交互界面和场景导入。

## 已有能力

- 二维位置与营地触发区。
- 进入区域、击败指定敌人组、打开宝箱三个有序任务阶段。
- 简化战斗、交互距离、死亡与离场状态。
- 宝箱锁定/可开启/已开启状态，奖励只发一次。
- 显式场景配置与输入校验。
- Node 和浏览器通用的无依赖引擎，16 组离线测试。

## 运行测试

需要 Node.js 18 或更高版本，无第三方依赖：

```sh
npm test
```

也可直接运行：

```sh
node sandbox/test-world.cjs
```

## 文件

- `sandbox/world.js`：状态引擎。
- `sandbox/scenarios/camp-demo.json`：合成演示场景。
- `sandbox/test-world.cjs`：规则测试。
- `sandbox/README.md`：引擎接口与模拟边界。

## 模拟范围

演示场景的坐标、敌人、伤害和任务条件均为自定义测试数据，并非真实原神任务、地图或宝箱数据。移动按二维直线简化，当前不运行原神、BetterGI、OCR 或真实键鼠输入。

模拟通过仅代表配置规则和程序逻辑通过；三维地形、实际导航、截图识别、真实战斗和宿主接口兼容性需要另外验证。

## 云端接续目标

制作可操作的二维任务沙盘，显示角色、敌人、触发区、宝箱、任务进度和事件日志；支持场景 JSON 导入、逐步执行和重置。真实点位导入需单独记录来源、版本、地图层和坐标系，解锁规则由场景配置补充。
